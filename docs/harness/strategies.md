# Harness strategies

Generated by aia-harness for a **TypeScript** project (commands source: package.json scripts + config).

## Lint & format
- Lint: `npm run lint`
- Format: `npm run format`

## Compilation / typecheck
- `npx tsc --noEmit`

## Language server
- Suggested LSP: `npx -y typescript-language-server --stdio` (see `.lsp.json`).

## Unit testing
- `npm run test`

## Canonical command reference
- **Install:** `npm install`
- **Lint:** `npm run lint`
- **Format:** `npm run format`
- **Typecheck:** `npx tsc --noEmit`
- **Test:** `npm run test`
- **Build:** `npm run build`
